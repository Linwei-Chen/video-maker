# 调研与文案规范（阶段 1~2 详细操作）

## 1. 调研方法（按输入类型）

### 1.1 论文输入
1. 拿到 PDF/DOI/arXiv 链接 → 全文通读（本机装有文献下载类技能则配合使用）。
2. 建事实表 `docs/facts.md`，模板：

```markdown
| # | 事实/数字 | 出处（章节/图/表） | 入片位置 | 置信度 |
|---|---|---|---|---|
| 1 | 所提方法在分割基准 +2.3 mIoU | 论文 Table 2 | 第 5 幕 | 原文数字 ✅ |
| 2 | c² ≈ 9×10¹⁶ m²/s² | 常识/教科书 | 第 10 幕 | 公认 ✅ |
```

3. 提取顺序：问题定义 → 现有方法缺陷 → 核心机制（一句话能说清吗？）→ 关键数字（主表主图）→ 消融/证据 → 局限与未来。
4. 论文原图可以截用（注明「示意」角标若重绘）；**重绘数据图必须用论文原始数字**。

### 1.2 网页/主题/概念输入
- WebFetch 全文；WebSearch 至少 2 轮、2 个独立权威源交叉。
- 历史事件：核对**人名全名、年代、数值、单位**（迈克尔逊-莫雷是 1887；光速 299,792,458 m/s 这类数字宁可进字幕不进口播）。
- 有争议/前沿不定的内容，明确说「目前主流观点是…仍有争论」，不站队。

### 1.3 受众双线原则
- 小白线：每幕给一个**可感比喻**（光子钟、绷紧的网、分子剪刀）。
- 专业线：至少一处**定量核心**（公式推导或真实数据），且数字来自事实表。
- 自查问题：「外行看完能复述吗？内行看完觉得准确吗？」

## 2. 旁白写作规范（量化，来自多支成片的实测统计）

| 指标 | 数值 |
|---|---|
| 每幕字数 | 48~60 字（均值 ~52） |
| 每幕句数 | 2~4 句（均值 2.4） |
| 句长 | 中位数 ~16 字，最长 ≤44 字（长句靠逗号/分号切字幕块） |
| 幕时长公式 | `max(设计时长, 字数/4.5 + 1.5s)`，build.py 里写 assert 硬校验 |
| 朗读语速实测 | edge-tts 云健 5~6 字/秒；`synth_fit` 会自动提速适配，但文案本身要留余量 |

写法要点（留存导向，实测有效）：
- **开头钩子用年代+场景或反差事实**：「1905年，伯尔尼专利局。」「但光速很顽固。」
- **比喻先行、术语后置**：先画现象，再点名词——「用光做钟……这就是时间膨胀」。
- **数字朗读改写**：299,792,458 → 「每秒约三十万公里」（字幕可写精确值）；1933 → 「一九三三年」。
- **拟人情绪锚点**：「爱因斯坦迎来最快乐的想法」。
- **收尾 = 金句 + 开放问题**：「时空不是舞台，而是演出本身。」
- 超长先精简文案，不要砍场景。

## 3. TTS 术语表（PRON 读法表）

配音前在文案头部维护读法表，合成时替换：
- 缩写逐字母：CVPR → C-V-P-R；SOTA → S-O-T-A
- 数字+单位防误读：1.8× → 「一点八倍」；5G → 「5G」（防读「五克」）；× → 「乘」
- 生僻词注音；人名给标准中译
- 合成后**截断守卫**：音频时长 < 字数×0.10s 视为断流废片，narration.py 已内置重试

## 4. 审稿门（阶段 2 放行条件，不得跳过）

1. 文案+分镜写完 → 交给**另一个更强的模型**独立审稿（审稿类技能 / 直调更强模型的聊天接口 / 再派一个独立 Agent，任何途径均可），提示词包含：
   - 全部旁白文本与分镜对照表
   - 审稿维度：**事实准确性（对照事实表）/ 叙事主线是否单一清晰 / 每句是否推动理解 / 前 5 秒钩子强度 / 有无口号式空话 / 术语密度是否适合双受众**
2. 有任何一条不满意 → 修改 → 重审。**全部满意才进入渲染**（审稿实践中出现过初稿连续两轮全被驳回、磨到第 9 轮才全票满意的记录——宁可慢，不可将就）。
3. 审稿意见与修改存 `docs/reviews/ep*_review*.md`，最终稿标注「R{n} 满意」。

## 5. 分镜表模板（写进 docs/plan.md）

| 幕 | 时长 | 画面元素 | 旁白要点 | 教学目标 | 高光? |
|---|---|---|---|---|---|
| 01 | 12.5s | 星空→网格弯曲→主标题 | 1905年奇迹年…… | 建立时空观 | ★ |

- 「画面元素 vs 旁白要点」**逐幕对照**，防图文错位（字幕讲 A 画面是 B 是高发事故）。
- 每片规划 ≥2 个**高光镜头**（可传播记忆点，如光钟推导 γ、真实频谱对比）。
- 全片时长目标：单主题 100~150s；旗舰 150~180s；论文深讲每集 200~240s。
